# 聖經目錄大挑戰

單人聖經目錄選擇題遊戲，適合練習聖經 66 卷書的名稱與順序。

## 功能

- 舊約、新約或混合抽考
- 隨機四選一題目
- 可選擇每回合題數
- 即時顯示答題結果
- 成績統計與錯題重練
- 支援電腦及手機

## 使用方式

開啟網站，選擇抽考範圍與題數即可開始。

## GitHub Pages 部署

1. 將專案檔案上傳至 GitHub Repository。
2. 進入 `Settings → Pages`。
3. Source 選擇 `Deploy from a branch`。
4. Branch 選擇 `main`，資料夾選擇 `/(root)`。
5. 儲存設定，等待部署完成。

## 技術

HTML、CSS、JavaScript，無需後端及資料庫。
